# Buddy Verse Mobile 📱🌐

**Buddy Verse** is a mobile social application designed to connect people through **real-time matching**, inspired by Tinder-style interactions but focused more broadly on **friendship, communication, and meaningful social connections**.

The platform leverages **real-time technologies, AI, and cloud services** to help users discover compatible connections, communicate instantly, express themselves through personalized digital identities, and unlock premium features via membership plans.

---

## 🚀 Project Vision

Buddy Verse aims to:
- Enable fast and natural **real-time user matching**
- Build a safe, interactive, and engaging social environment
- Enhance user experience with **AI-powered personalization**
- Encourage authentic connections beyond traditional dating apps
- Provide premium value through **subscription-based membership**

---

## 🌟 Main Features

### ❤️ One-to-One Matching
- Real-time matching between two users
- Instant match updates and notifications

### 👥 Group Chat & Communities
- Join and participate in group chats
- Real-time group messaging powered by SignalR
- Foundation for future community-based social features

### 💬 Real-Time Chatting
- One-to-one and group conversations
- Low-latency real-time message delivery
- Smooth and reliable chat experience

### 📝 Social Posts & Interactions
- Create and share posts with the community
- Like and comment on posts
- Increase engagement and social interaction

### 🤖 AI Avatar & Character Generation
- Generate personalized avatars using Gemini AI
- Create unique AI-generated characters for user profiles
- Visual customization based on personality and preferences

### 💎 Membership & Subscription
- Multiple membership plans (Basic / Premium / VIP)
- Unlock exclusive features and enhanced experiences
- Subscription management within the app

### 💳 Online Payment with PayOS
- Secure subscription payments via **PayOS**
- Support for local and online payment methods
- Real-time payment status verification
- Seamless upgrade and renewal flow

## 🤖 Gemini AI – Personalized Avatar & Character Generation

Gemini AI is integrated into **Buddy Verse** to generate **personalized avatars and characters** that represent each user’s unique identity.

Using Gemini AI, the platform can:
- Generate **custom avatar images** tailored to user preferences
- Create personalized characters reflecting personality, interests, and style
- Support dynamic visual generation for profiles and future social features
- Enhance emotional connection and user engagement

This AI-driven visual personalization helps make every user experience more immersive and unique.
